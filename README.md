# HomeSpace 🏠

A modern real estate platform connecting property seekers with agents and agencies across different locations.

## Overview

HomeSpace is a full-featured real estate marketplace that makes it easy to discover, list, and manage properties. Whether you're looking to buy, rent, or sell — HomeSpace provides a seamless experience for property seekers and real estate professionals alike.

## Features

- **Property Listings** — Browse properties for sale or rent with detailed information, photos, and pricing
- **Agency Directory** — Discover verified real estate agencies and connect with trusted agents
- **Agent Dashboard** — Manage listings, track views and inquiries, and update agency profiles
- **User Profiles** — Save favorite properties, manage account settings, and create your own agency
- **Advanced Search** — Filter properties by location, price, type, and amenities
- **Responsive Design** — Optimized for mobile, tablet, and desktop devices
- **Dark Mode** — Full dark theme support for comfortable browsing

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS, shadcn/ui
- **State Management:** Zustand
- **API:** Apollo Client (GraphQL)
- **Forms:** React Hook Form, Zod
- **Icons:** React Icons
- **Deployment:** Vercel

## Getting Started
```bash
# Clone the repository
git clone https://github.com/uggoprince/homespace-frontend.git

# Navigate to project directory
cd homespace-frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

## Project Structure
```

├── app/            # Next.js App Router pages and layouts

├── lib/            # Utility libraries
├── providers/      # Context providers
├── schemas/        # Zod validation schemas
├── stores/         # Zustand state stores
```
